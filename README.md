# Novi Landing Page
 
A modern, responsive landing page for Novi built with cutting-edge web technologies and best practices.
 
## 🌐 Live Demo
 
[Deployed on Vercel](https://novi-opal.vercel.app/)

This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## 📋 Tech Stack
 
- **Framework:** [Next.js](https://nextjs.org/) — React meta-framework for production-grade applications
- **UI Components:** [shadcn/ui](https://ui.shadcn.com/) — High-quality, accessible React components built on Radix UI
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) — Utility-first CSS framework for rapid UI development
- **Form Validation:** [Zod](https://zod.dev/) — TypeScript-first schema validation library
- **Form Management:** [React Hook Form](https://react-hook-form.com/) — Efficient, flexible form handling with minimal re-renders
- **Deployment:** [Vercel](https://vercel.com/) — Optimized hosting for Next.js applications

## ✨ Features
 
- Fully responsive design (mobile, tablet, desktop)
- Optimized performance with Next.js image optimization
- Type-safe forms with Zod validation and React Hook Form
- Accessible UI components from shadcn/ui
- Clean, maintainable code structure
- SEO-optimized landing page

## 🚀 Getting Started
 
### Prerequisites
 
Ensure you have the following installed:
- **Node.js** (v18 or higher)
- **npm** or **pnpm** package manager

> **Recommendation:** This project uses pnpm for faster and more efficient dependency management, but npm works just as well.

### Installation
 
1. **Clone the repository:**
```bash
   git clone https://github.com/biwashpra/Novi.git
   cd Novi
```
 
2. **Install dependencies:**
   Using **npm**:
```bash
   npm install
```
 
   Or using **pnpm**:
```bash
   pnpm install
```
 
### Development
 
Run the development server:
 
Using **npm**:
```bash
npm run dev
```
 
Or using **pnpm**:
```bash
pnpm dev
```
 
Open [http://localhost:3000](http://localhost:3000) in your browser to view the landing page. The page will automatically reload as you make changes.
 
### Production Build
 
Create an optimized production build:
 
Using **npm**:
```bash
npm run build
```
 
Or using **pnpm**:
```bash
pnpm build
```
 
Start the production server:
 
Using **npm**:
```bash
npm start
```
 
Or using **pnpm**:
```bash
pnpm start
```
